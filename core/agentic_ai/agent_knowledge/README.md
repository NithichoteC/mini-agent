# agent_knowledge/

Curated knowledge resources bound to agents: reference files, domain guidance,
ontology material, policy files, reusable context resources.

This is **not** runtime memory (`memory/`) and **not** executable agent definitions (`agent/`).
Content here is static, reviewed, and version-controlled; agents read it, they do not write it.

Organisation (per agent, per domain, or shared) is not yet decided.
